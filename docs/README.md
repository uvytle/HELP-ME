# docs/

Repo-specific memory: decisions and rationale for this project, tracked in git so any
dev (or a future Claude Code session with no chat history) can read *why* things are
the way they are, not just what changed.

This is **not** the published website — that lives at the repo root (`index.html`,
`css/`, `js/`, `assets/`, `pages/`). See [DECISIONS.md](DECISIONS.md) for the log.

Add an entry whenever you make a non-obvious call: what was decided, why, what was
ruled out, and who asked for it if relevant. Newest entry on top.
